Community feedback for students

Luminar is a lightweight platform that helps student communities gather structured feedback on courses, projects, and campus activities.

Get in touch Project README

About the project

This project aims to make it easy for students and student organizations to request, collect, and analyze feedback. The repository contains a small backend and frontend to demonstrate the core flows. See `backend/be.txt` and `frontend/fe.txt` for implementation notes.

Tech & workflow

  • Simple static frontend under `frontend/` (see `frontend/portfolio.html`, `frontend/styles.css`).
  • Backend notes in `backend/be.txt` (API stubs / data model ideas).
  • Run a quick preview by opening `frontend/portfolio.html` in a browser or serving the folder with a static server (e.g., `npx http-server` or Python's `http.server`).
