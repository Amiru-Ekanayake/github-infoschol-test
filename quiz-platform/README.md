# Quiz Platform

This project is a simple quiz platform built using HTML, CSS, and JavaScript. It consists of a frontend that handles the user interface and a backend that serves quiz data.

## Features

- Interactive quiz interface
- Score tracking
- Randomized questions

## Getting Started

### Prerequisites

- A modern web browser
- Node.js (for backend)

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd quiz-platform
   ```

3. For the backend, install the necessary dependencies:
   ```
   npm install
   ```

### Running the Application

- To run the frontend, simply open `frontend/index.html` in your web browser.
- To start the backend server, run:
   ```
   node backend/server.js
   ```

## Usage

Follow the on-screen instructions to take the quiz. Your score will be displayed at the end.
